Installation

Via npm / yarn / pnpm 
npm install @synapxlab/cookie-consent
# ou
yarn add @synapxlab/cookie-consent
pnpm add @synapxlab/cookie-consent

Dans votre bundle (ex: src/js/bundle.js) :

import '@synapxlab/cookie-consent';
Via balise <script> HTML

Placez ce script avant votre JS principal :

<script src="https://unpkg.com/@synapxlab/cookie-consent@2.2.0/dist/bundle.js"></script>
⚛️ React (Vite / CRA) 
// src/main.jsx
import '@synapxlab/cookie-consent';
import React from 'react';
import ReactDOM from 'react-dom/client';
import App from './App.jsx';

ReactDOM.createRoot(document.getElementById('root')).render(<App />);

🆕 Nouveautés v2.2.0

Affichage automatique des services

Les services configurés (Google Analytics, AdSense, Facebook Pixel) sont maintenant automatiquement détectés et affichés dans les descriptions des catégories.

Exemple :

  • 📊 Statistiques
    Services : Google Analytics
  • 📢 Marketing
    Services : Google AdSense, Facebook Pixel

Ajout de 3 nouvelles langues avec détection automatique :

  • 🇩🇪 Deutsch
  • 🇮🇹 Italiano ✨ NOUVEAU
  • 🇳🇱 Nederlands ✨ NOUVEAU
  • 🇵🇹 Português ✨ NOUVEAU

CSS entièrement encapsulé

Tous les styles sont isolés dans #politecookiebanner pour éviter tout conflit avec votre site.

Bundle ultra-léger

Seulement ~5 KB gzippé (les 7 langues ajoutent moins de 2 KB !)

Utilisation

Le script injecte la bannière au chargement. Les catégories sont cachées par défaut et s'affichent uniquement quand l'utilisateur clique sur « Les préférences ». Les choix sont stockés dans localStorage sous la clé politecookiebanner.

Ajouter dans le footer de votre page HTML :

<div id="openpolitecookie">
  <a href="#">Gérer les cookies</a>
</div>

API JavaScript

// Ouvrir la bannière
window.CookieConsent.open();

// Ouvrir avec préférences visibles
window.CookieConsent.open(true);

// Réinitialiser
window.CookieConsent.reset();

// Obtenir les préférences
const prefs = window.CookieConsent.getPreferences();

// Vérifier un consentement
if (window.CookieConsent.hasConsent('statistics')) {
  console.log('Analytics autorisé');
}

Outils de test rapide

RÈGLE D'OR : Tant que l'utilisateur n'a pas consenti à une catégorie, ne chargez pas les scripts tiers (Google Analytics, pixels publicitaires, etc.) et ne déposez pas leurs cookies.

✅ Strictement nécessaire → toujours actif (non refusables).
❌ Statistiques / Marketing refusés → rien ne doit être chargé.

Configuration

Configuration complète

window.CookieConsent.init({
  // Logging des consentements (optionnel)
  logger: {
    enabled: true,
    endpoint: '/api/consent/log',
    apiKey: 'votre-api-key',
    anonymousId: true,
    headers: {
      'X-CSRF-TOKEN': document.querySelector('meta[name="csrf-token"]')?.content
    }
  },
  
  // Google Analytics
  statistics: {
    google_manager_key: 'G-XXXXXXXXXX'
  },
  
  // Services marketing
  marketing: {
    google_AdSense_key: 'ca-pub-XXXXXXXXXXXXXXXX',
    facebook: {
      key: 'VOTRE-PIXEL-ID',
      track: 'PageView'
    }
  }
});

Configuration minimale

window.CookieConsent.init({
  statistics: {
    google_manager_key: 'G-XXXXXXXXXX'
  }
});
Comportement automatique :
  • Si google_manager_key configurée → Affiche "Services : Google Analytics"
  • Si google_AdSense_key configurée → Affiche "Services : Google AdSense"
  • Si facebook.key configurée → Affiche "Services : Facebook Pixel"
  • Si aucune clé → Pas de ligne "Services"

Personnalisation CSS

La bannière utilise des variables CSS pour une personnalisation facile. 4 thèmes intégrés : default, brown, dark, blue.

Commutateur de thème (démo)

Appliquez le thème sur <body class="cookie-theme-default">

Variables CSS personnalisables

:root {
  --cc-bg: #ffffff;
  --cc-text: #111827;
  --cc-muted: #6b7280;
  --cc-line: #e5e7eb;
  --cc-surface: #f3f4f6;
  --cc-accent: #18a60b;
}

Exemple de page (démo)

<!doctype html>
<html lang="fr">
<head>
  <meta charset="utf-8" />
  <meta name="viewport" content="width=device-width,initial-scale=1" />
  <title>Gérer le consentement aux cookies</title>
</head>
<body class="cookie-theme-default">
  <footer>
    <div id="openpolitecookie">
      <a href="#">Gérer les cookies</a>
    </div>
  </footer>

  <!-- Charger le bundle -->
  <script src="https://unpkg.com/@synapxlab/cookie-consent@2.2.0/dist/bundle.js"></script>
  
  <!-- Configuration -->
  <script>
    window.CookieConsent.init({
      statistics: {
        google_manager_key: 'G-ABC123XYZ'
      }
    });
  </script>
</body>
</html>
