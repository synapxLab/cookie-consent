📦 Installation

Via npm / yarn / pnpm 
npm install @synapxlab/cookie-consent
            # ou
            yarn add @synapxlab/cookie-consent
          pnpm add @synapxlab/cookie-consent

Dans votre code :

import '@synapxlab/cookie-consent';
Via CDN (script HTML) 
<script src="https://cdn.jsdelivr.net/npm/@synapxlab/cookie-consent@2.1.3/dist/cookie.min.js"></script>

🚀 Utilisation

Ajoutez ce lien dans votre footer pour permettre la gestion des cookies :

<a href="#" id="openpolitecookie">Gérer les cookies</a>

API JavaScript

// Ouvrir la bannière
        window.CookieConsent.open();

        // Ouvrir avec préférences visibles
        window.CookieConsent.open(true);

        // Réinitialiser
        window.CookieConsent.reset();

        // Obtenir les préférences
        const prefs = window.CookieConsent.getPreferences();

        // Vérifier un consentement
        if (window.CookieConsent.hasConsent('statistics')) {
          console.log('Analytics autorisé');
        }

💼 Solution pensée pour les agences web et développeurs

  • ✅ Gérer plusieurs sites clients depuis un seul compte

⚙️ Configuration

Configuration complète (avec logger)

window.CookieConsent.init({
          logger: {
            enabled: true,
            apiKey: 'sk-live-xxxxxxxxxxxxx',  // 🔑 Depuis l'espace membre
            anonymousId: true,
            headers: {
              'Authorization': 'Bearer apk_xxxxx'
            }
          },
          statistics: {
            google_analytics_key: 'G-XXXXXXXXX',  // ✅ Google Analytics
            hotjar_site_id: '1234567'             // ✅ Hotjar
          },
          marketing: {
            google_adsense_key: 'ca-pub-xxxxx',   // ✅ Google AdSense
            facebook_pixel: {
              key: 'YOUR-PIXEL-ID',
              track: 'PageView'
            }
          }
        });

Configuration minimale (sans logger)

window.CookieConsent.init({
          statistics: {
            google_analytics_key: 'G-XXXXXXXXX'
          }
        });
